# 🚀 Java OOP Console Applications

A repository featuring two core Java applications demonstrating Object-Oriented Programming (OOP) concepts, system architecture, and clean code practices.

Developed by **Karim**.

---

## 📌 Projects Included

### 1. 🛒 E-Commerce System (`Main.java`)
* **Key Features:** User/Admin management, product stock tracking, dynamic ordering, and payment processing (Credit Card & PayPal).
* **OOP Concepts:** Encapsulation, Polymorphism, Inheritance, Exception Handling.

### 2. 🅿️ Trace Slot - Parking Management System (`ParkingSystem.java`)
* **Key Features:** Real-time parking slot availability, interactive reservation system, and occupancy validation.
* **OOP Concepts:** Domain Design, State Management, Collections Framework.
